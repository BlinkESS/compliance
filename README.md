# Your Company

A static site with a privacy policy and terms of use, meant to be published with GitHub Pages from the repository root.

## Pages

- `/` — home
- `/privacy.html` — privacy policy
- `/terms.html` — terms of use
- `/deletion.html` — data deletion instructions

The company name **Your Company** and the address **contact@example.com** are placeholders. Replace them before you publish.

These documents are templates, not legal advice.

## Publish on GitHub Pages

1. Push this repository to the `main` branch.
2. In the repository on GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch **main** and folder **/ (root)**, then save.

GitHub will serve the files as-is. A `.nojekyll` file is included so Pages does not run Jekyll.
